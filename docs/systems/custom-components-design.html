Triển khai trong codebase

Style A đã được áp dụng qua design tokens tập trung, Ant Design ConfigProvider, Tailwind hub-* và wrapper Custom*.

  • src/constants/custom-components.constant.ts — màu, class map, modal width, touch height
  • src/styles/globals.css — CSS variables --hub-*, focus ring, Plus Jakarta Sans
  • src/contexts/ColorModeContext.tsx — colorPrimary: #2563EB, layout/card/menu/table tokens
  • tailwind.config.ts — colors.hub.*, background
  • Import: import { CustomButton, TableContainer } from '@/components/custom'

Patterns chính

Các composition thường gặp — kết hợp nhiều Custom* thành flow hoàn chỉnh.

TableContainer + CustomFilter

List page Refine: header (title + actions) → filter → bảng / list mobile → pagination. Desktop: filter panel luôn hiển thị dạng grid. Mobile: search full width + nút “Bộ lọc” / “Thu gọn bộ lọc”. 

// Page module
import { TableContainer, CustomButton } from '@/components/custom';
import { useTableContainer } from '@/hooks';

const table = useTableContainer({ resource: 'providers' });

<TableContainer
  tableContainerData={table}
  title="Data providers"
  filterSearch={{ placeholder: 'Tìm kiếm...' }}
  customFilterItems={[...]}
  columns={columns}
/>

CRUD & danh sách

Pattern Refine: filter + bảng + modal form. Luôn bọc trong TableContainer.

TableContainer

@/components/custom/custom-container · export TableContainer

Orchestrator list page: tiêu đề, action buttons, CustomFilter, CustomTable (desktop) hoặc ListItem cards (mobile), PaginationControls. Kết nối useTableContainer.

Props: tableContainerData, columns, filterSearch, customFilterItems, actionButtons

Mobile: ListItem thay table; filter collapse; action buttons wrap

CustomFilter

@/components/custom/custom-filter

Bộ lọc search + select theo FilterItem[]. Desktop: panel trắng, grid 3 cột + “Xóa lọc”. Mobile: search trên, select trong panel thu gọn, badge đếm filter active.

Props: filterActions, filterValues, onClearFilters 

<CustomFilter
  filterActions={filterItems}
  filterValues={filters}
  onClearFilters={() => setFilters([])}
/>

Mobile: Col span 24; nút “Bộ lọc” / “Thu gọn bộ lọc”; badge primary

CustomTable

@/components/custom/custom-table

Wrapper Table Ant Design + cột action (edit/delete), sort, row selection. Header nền #F8FAFC qua ConfigProvider. 

<CustomTable
  columns={columns}
  tableProps={tableProps}
  loading={isLoading}
  actionItems={[{ type: 'edit' }, { type: 'delete' }]}
/>

Mobile guidelines

  • CustomFilter: search full width; select trong panel collapse; badge bg-hub-primary
  • CustomButton CTA: block touchFriendly full width khi là action chính
  • CustomModal: calc(100vw - 32px); form 1 cột; scroll trong body
  • CustomTable: scroll.x hoặc ListItem qua TableContainer
  • CustomStatistic.Group: grid 2 cột; tối đa 2 hàng KPI trước main
  • Touch: Input/Button ≥ 44px (touchFriendly / ConfigProvider controlHeightLG)

Do / Don't

Do Luôn import từ @/components/custom
Do Bọc list trong TableContainer / CustomCard
Do Constants vào custom-components.constant.ts
Do Dùng hubVariant="cta" cho action cam, status trên CustomTag
Don't Import Ant Design trực tiếp khi đã có wrapper
Don't Nested card trong card
Don't Gradient/glass trên layout shell
Don't Hardcode #1840DC / indigo — dùng hub-primary
