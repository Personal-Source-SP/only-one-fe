Tổng quan

Minimal & Swiss là hướng thiết kế chính cho Only One Hub: giao diện sạch, grid rõ ràng, một accent màu (blue), tối ưu cho dashboard đa module (scraping, schedule, Google integrations).

Font: Plus Jakarta Sans

Keywords: clean, spacious, functional, high contrast, grid-based, accessible

Phù hợp: SaaS, admin dashboard, productivity hub, Refine + Ant Design

Nguyên tắc thiết kế

Không gian trung tâm lớnSidebar/header gọn; main ≥70% viewport; padding 16–24px
Cấu trúc riêng biệtMỗi khối = surface + border + radius; gap section 24px
Màu đơn giản1 primary + 1 CTA + neutral; không gradient shell
Dễ sử dụngHit area ≥44px mobile; icon + label nav; Ant Design tokens
